### Rollback Plan

Before starting, create a git commit:
```powershell
git add -A
git commit -m "Snapshot before 12-23-25 PM cleanup"
git tag cleanup-snapshot
```

If something breaks:
```powershell
git reset --hard cleanup-snapshot
```

### Execution Order (Recommended)

1. Create snapshot commit
2. Phase 1 (safe, regenerable files)
3. Test dev server
4. Phase 3 (test files)
5. Phase 4 (configs) - TEST CAREFULLY

7. Phase 6 (scripts) - only after confirming primary script works
